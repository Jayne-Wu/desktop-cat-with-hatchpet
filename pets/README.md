# Pets Directory

This directory stores Codex/Hatchpet-compatible pet assets.

```text
pets/
  simba/
    pet.json
    spritesheet.webp
  xigua/
    pet.json
    spritesheet.webp
```

`xigua` is the built-in default pet for the app.

`simba` is also included as a bundled local pet and can be selected from the tray or the pet context menu.

Other local test pets can be placed in sibling folders, but they are ignored by Git unless explicitly allow-listed in `.gitignore`.
