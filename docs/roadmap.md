# Desktop Cat 路线图

这份文档记录 Desktop Cat 的版本方向。它不是当前功能清单；当前已经实现的能力以 README 和测试为准。

## 产品方向

Desktop Cat 的演进顺序是：

1. 先成为稳定可用的本地桌宠。
2. 再减少机械循环，让行为更像一个有节奏的伙伴。
3. 再让它真正生活在桌面边缘。
4. 最后逐步扩展成低打扰的工作陪伴应用。

## 已完成版本

### v1.1.x 基础可用性

目标：让用户能把宠物长期放在桌面上，不影响基础使用。

已完成：

- 本地宠物资源加载。
- 宠物切换：`xigua` 和 `simba`。
- 三档尺寸：小、中、大。
- 拖拽摆放。
- 记住窗口位置、宠物选择、尺寸等设置。
- 一键回到屏幕中央或右下角。
- 基础托盘和右键菜单。

### v1.2.x 行为节奏

目标：拆掉“每个动作一直循环播放”的刻板感。

已完成：

- 点击动作变成有限短动作，结束后回到自动行为。
- 点击反馈在 `waving`、`jumping`、`review` 之间按风格变化。
- 增加点击冷却，避免疯狂重复触发。
- 增加轻量 mood：`playful`、`curious`、`calm`、`sleepy`。
- 长时间无操作进入更安静的状态。
- 静态陪伴状态使用更慢、更有停顿感的播放节奏。

### v1.3.x 桌面移动和菜单整理

目标：让桌宠开始在桌面边缘生活，同时把菜单整理成可长期维护的结构。

已完成：

- 底部边缘自动移动。
- `observe`、`settle`、`stroll`、`rehome` 移动阶段。
- 窗口只在 `running-left` / `running-right` 动画激活后移动。
- 拖拽后延迟回到底部边缘。
- 陪伴风格：安静陪伴、好奇巡视、活泼玩耍、低打扰专注。
- 菜单中文 / English 切换。
- 菜单按宠物、外观、陪伴风格、交互、位置、语言重新分组。

### v1.4.x 图标和发布整理

目标：让应用更像一个完整可发布的小产品。

已完成：

- 使用西瓜和辛巴组合生成应用图标。
- Windows 窗口、托盘和打包配置使用 `build/icon.ico`。
- 打包产物命名为 `DesktopCat-v${version}.exe`。
- README 和行为说明文档整理。

## 后续规划

### 工作陪伴

目标：让桌宠和用户的工作节奏产生轻连接，但不变成高打扰工具。

候选能力：

- 专注时段：进一步降低移动和动作频率。
- 休息提示：工作一段时间后用轻动作提醒休息。
- 喝水、活动、休息眼睛等轻提醒。
- 勿扰时间段：在用户指定时间内保持低存在感。
- 手动状态入口：工作中、等待、审查、出错、完成。

### 自动降低存在感

目标：在用户需要沉浸或展示时减少打扰。

候选能力：

- 检测全屏窗口后降低移动频率或暂停动作。
- 检测游戏或演示场景后自动隐藏。
- 检测会议软件前台时进入低打扰风格。
- 提供明确的菜单开关，避免自动行为不可控。

### 个性化

目标：让用户愿意把它当成自己的桌宠。

候选能力：

- 宠物昵称。
- 透明度控制。
- 行为频率设置。
- 开机启动。
- 简单装饰物。
- 每只宠物自己的行为偏好。

### 多宠物和事件 hook

目标：让桌宠可以连接更多真实工作流。

候选能力：

- 多只宠物同时显示。
- 外部事件触发状态，例如构建失败触发 `failed`。
- 插件或本地脚本 hook。
- 更细的 `pet.json` 可选扩展字段。

## 非目标

当前阶段不追求：

- 复杂 AI 对话。
- 云端同步。
- 重量级任务管理。
- 侵入式提醒。
- 改变 Hatchpet/Codex 基础资源格式。
